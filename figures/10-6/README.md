# Figure 10-6

Title: Protected areas, 1990-2014

Current status: `verified_reproduction`

## Summary

Figure 10-6 has a verified book-period reconstruction. The accepted source is
an archived World Bank WDI bulk CSV captured by the Internet Archive on
2017-10-12. It reproduces the book-period land and marine protected-area trends
within visual and numeric tolerance.

The post-2014 extension uses current WDI successor values and is intentionally
shown as a separate successor series because the marine values are discontinuous
with the archived book-period release.
