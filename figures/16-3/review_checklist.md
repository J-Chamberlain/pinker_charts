# Review checklist
- [x] Original authorized PDF chart/title/caption/source inspected.
- [x] Original paper identity/method description resolved.
- [ ] Full surrounding Pinker text and complete paper independently reviewed.
- [x] Archived author data recovered,203 exact OWID checks,no digitization.
- [x] Current/historical/archived source versions distinguished and retained.
- [x] Comparable successor evaluated; projections rejected,updated estimates used.
- [x] Book and extended comparisons visually inspected,labels corrected.
- [x] Caption,provenance,lineage,anomaly/discrepancy/reviewer challenge documented.
- [x] Metadata,registry,project state,checksums and database updated.
- [ ] Independent publication approval completed.

Verified book reproduction is not a claim of independent publication acceptance.
Extension is explicitly an updated source estimate with methodological caveats.
