# Raw data

- `owid_clio_infra_life_expectancy_at_birth.csv`: public OWID repository copy of
  the Clio Infra birth series; accepted only as the cited pre-1845 component.
- `ons_expected_age_to_reach_males.csv`: public ONS 2015 data download; retained
  only as a male decennial diagnostic and never classified as book data.

See `provenance/provenance.md` for URLs, retrieval date, and source limitations.
